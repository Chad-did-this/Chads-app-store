## Installation

### 🟢 Android

1. Download the APK using the green button above.
2. Open the downloaded file.
3. If prompted, allow installation from your browser or file manager.
4. Install and open Chad's App Store.

The Android app can retrieve its catalog directly from GitHub. New Android builds use the permanent developer signing key. An installation made with an earlier temporary key needs a one-time reinstall; later updates keep the same signing identity.

### 🔵 iPhone

1. Set up [SideStore](https://sidestore.io/) or [AltStore Classic](https://altstore.io/).
2. Download the IPA using the blue button above, or add the [iPhone app source](https://github.com/Chad-did-this/Chads-app-store/releases/download/ios-source/source.json) to a compatible sideloading tool.
3. Use the tool to sign and install the application.

The IPA is unsigned and cannot be installed simply by tapping it. Apple account and device restrictions apply. Installation on a physical iPhone has not yet been verified.
